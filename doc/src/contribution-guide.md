# Contribution Guide

Start with the [Zrzur Web README](https://github.com/zrzur/web) (repository publication may still be pending) and the workspace [`CONTRIBUTING.md`](../../../CONTRIBUTING.md) when present.

## Local development

Follow the Development section in `web/README.md` (`mise install:frozen`, `mise build:deps`, `mise dev`).

## Contribution policy

- Prefer Issues labeled for contribution once the public repository exists.
- Communicate on the issue before large changes to avoid duplicate work.
- Keep pull requests focused; preserve AGPL attribution.
- Do not use Stoat community invite links or Stoat developer docs as Zrzur support channels.

Upstream Stoat for Web remains at https://github.com/stoatchat/for-web for provenance only.
