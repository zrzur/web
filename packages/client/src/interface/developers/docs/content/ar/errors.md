# الأخطاء

كل نوع خطأ يمكن أن تعيده الواجهة، مع سببه وحله.

## صيغة الخطأ {#format}

@@0

افحص `type` ولا تعتمد على النص أبدًا. الأنواع ثابتة: لا يُعاد تسميتها ولا تُحذف. قد تظهر أنواع جديدة في السيرفرات الأحدث، فعامل النوع المجهول كفشل عام.

## ماذا تفعل بالخطأ {#what-to-do}

| الحالة       | المعنى                 | ما تفعله                                         |
| ------------ | ---------------------- | ------------------------------------------------ |
| `400`, `422` | الطلب خاطئ             | صحّحه. سيفشل الطلب نفسه مجددًا                   |
| `401`        | الرمز خاطئ             | أوقف البوت وتحقق من الرمز                        |
| `403`        | لا يحق للبوت هذا        | أخبر الشخص. لا تُعد المحاولة                     |
| `404`        | غير موجود              | انسه                                             |
| `409`        | تعارض                  | اجلب الحالة الحالية                              |
| `429`        | طلبات كثيرة            | انظر [حدود المعدل](/developers/docs/rate-limits) |
| `5xx`        | فشل من جهتنا           | أعد المحاولة بمهلة متزايدة، من ثلاث إلى خمس مرات |

الأخطاء الصادرة من سيرفر الويب نفسه (لا رمز، أو مسار مجهول، أو جسم ليس JSON) هي JSON أيضًا. تحقق من الحالة قبل تحليل الجسم، فقد يجيب وسيط بينكما بصفحة HTML.

## هل البوت في ذلك السيرفر؟ {#not-installed}

لا يرى البوت إلا السيرفرات التي ثُبّت فيها. أما السيرفر الذي ليس فيه، فتختلف الإجابات بحسب المسار:

| الطلب                                                        | الجواب                    |
| ------------------------------------------------------------ | ------------------------- |
| `GET /servers/{target}`                                      | `404 NotFound`            |
| `GET /channels/{target}` لإحدى قنواته                        | `404 NotFound`            |
| `POST /channels/{target}/messages` لإحدى قنواته              | `403 MissingPermission`   |

لذلك قد يعني `403 MissingPermission` حين يكتب بوتك في قناة أعطاه أحدهم معرّفها أن البوت غير مثبّت هناك. اسأل `GET /channels/{target}`: يعني `404 NotFound` أن البوت ليس في ذلك السيرفر (أو أن القناة غير موجودة)، فثبّت البوت أولًا برابط الدعوة من بوابة المطورين. ويعني `403 MissingPermission` هناك أن البوت في السيرفر لكنه لا يرى القناة: القناة الخاصة تحتاج إلى رؤية القناة لأحد أدوار البوت.
