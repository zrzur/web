# الرسائل

يرسل البوت رسائله ويعدلها ويحذفها، ويتفاعل، ويثبّت، ومع **إدارة الرسائل** يحذف رسائل الآخرين.

## أرسل رسالة {#send-a-message}

@@0

- **الحدود**: يسردها `GET /` لكل سيرفر (افتراضيًا 2000 حرف، و5 مرفقات، و10 تضمينات، و5 ردود، و20 تفاعلًا مختلفًا للرسالة).
- **عدم التكرار**: أرسل الترويسة `Idempotency-Key` بقيمة فريدة. إذا أُعيد الطلب بالمفتاح نفسه لا تُرسل الرسالة مرتين.
- **الرسائل الصامتة**: `flags: 1` يرسل دون إشعارات.
- **التنكر**: يُظهر `masquerade: { name, avatar }` اسمًا وصورة أخرى على الرسالة (يتطلب Masquerade، ويتطلب `colour` إدارة الأدوار أيضًا).
- **المكوّنات**: أزرار وقوائم وكتل تخطيط، والبوتات وحدها ترسلها. انظر [الأزرار والقوائم والنماذج](/developers/docs/components).
- **الذكر**: `<@user id>` يذكر مستخدمًا، و`<%role id>` يذكر دورًا (يتطلب Mention Roles)، و`@everyone` و`@online` يتطلبان Mention Everyone.

## الرد {#reply}

يرد `replies` على رسائل سابقة، حتى 5. `id` هو الرسالة، و`mention` يحدد هل يصل صاحبها تنبيه، و`fail_if_not_exists: false` يرسل حتى لو اختفت تلك الرسالة.

## التعديل والحذف {#edit}

يأخذ `PATCH /channels/{target}/messages/{msg}` الحقول `content` و`embeds` و`components`. لا يعدّل البوت إلا رسائله. ويحذف `DELETE /channels/{target}/messages/{msg}` رسالة البوت، أو أي رسالة مع إدارة الرسائل. لا يرسل التعديل تنبيهًا جديدًا أبدًا.

## التضمينات {#embeds}

التضمين بطاقة تحت الرسالة. يتطلب إرسالها صلاحية Send Embeds.

| الحقل           | المعنى                                        |
| --------------- | --------------------------------------------- |
| `title`         | العنوان                                       |
| `description`   | نص بصيغة Markdown                             |
| `url`           | العنوان الذي يشير إليه الرابط                 |
| `colour`        | لون CSS، مثل `#E0195F`                        |
| `icon_url`      | صورة صغيرة بجانب العنوان                      |
| `media`         | معرّف ملف رفعته، يظهر صورة                    |
| `image_url`     | عنوان صورة كبيرة                              |
| `thumbnail_url` | عنوان صورة صغيرة في الجانب                    |
| `author`        | `name` و`url` و`icon_url`                     |
| `fields`        | حتى 25، لكل منها `name` و`value` و`inline`    |
| `footer`        | `text` و`icon_url`                            |
| `timestamp`     | تاريخ يظهر في الأسفل                          |

الحقول والحدود الدقيقة في [المرجع أدناه](/developers/docs/messages#post-channels-target-messages).

## المرفقات {#attachments}

تشير الرسالة إلى الملفات بمعرّفاتها. ارفع أولًا ثم أرسل. يصلح المعرّف مرة واحدة: يجيب الاستخدام الثاني بـ`404 NotFound`. يتطلب الإرسال Upload Files.

@@2

انظر [الملفات](/developers/docs/files) للأحجام والأنواع.

## اقرأ الرسائل {#read-messages}

يعيد `GET /channels/{target}/messages` حتى 100 رسالة، وتتنقل بالمعاملات `before` أو `after` أو `nearby`. أضف `include_users=true` لتحصل على الكتّاب في الاستجابة نفسها. تتطلب القراءة رؤية القناة وقراءة الرسائل السابقة.

البحث النصي للأشخاص فقط، وتحصل البوتات على `IsBot`، لأنه سيتيح لها قراءة ما تخفيه نيّات الاتصال. تستطيع البوتات سرد الرسائل المثبتة (انظر [التثبيت والتفاعلات](/developers/docs/messages#pins-and-reactions)). وصندوق الإشارات للأشخاص فقط أيضًا.

## الحذف الجماعي {#bulk-delete}

يحذف `DELETE /channels/{target}/messages/bulk` حتى 100 رسالة دفعة واحدة. لا تُحذف جماعيًا الرسائل الأقدم من أسبوع، فاحذفها واحدة واحدة.

## الرسائل الخاصة {#direct-messages}

يفتح `GET /users/{target}/dm` قناة الرسائل الخاصة مع مستخدم أو يعيدها. وتعتمد قدرة البوت على الكتابة هناك على إعدادات خصوصية الشخص وحظره، انظر [المستخدمون والأعضاء](/developers/docs/users#privacy-limits).

## التثبيت والتفاعلات {#pins-and-reactions}

يضيف `PUT /channels/{target}/messages/{msg}/reactions/{emoji}` تفاعل البوت، ويزيله `DELETE` على المسار نفسه. يُكتب الرمز التعبيري في المسار بترميز URL (`%F0%9F%91%8D` لرمز الإعجاب)، أو بمعرّف رمز مخصص. ويثبّت `POST /channels/{target}/messages/{msg}/pin` رسالة. ويسرد `POST /channels/{target}/search` مع `pinned: true` الرسائل المثبتة. أما البحث الآخر فللأشخاص فقط: تحصل البوتات على `IsBot`، لأنه سيتيح لها قراءة ما تخفيه نيّات الاتصال.
