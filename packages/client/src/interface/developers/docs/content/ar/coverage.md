# الحالة والتغطية

## كيف تُصنع هذه الوثائق {#how-these-docs-are-made}

1. يقرأ برنامج كود مسارات السيرفر وفحوص صلاحياته وجداول أخطائه وحدود معدله وأحداث بوابته والمكتبتين ومستند OpenAPI، ويكتب الجرد الذي تُبنى منه هذه الصفحات. لا يُكتب هنا يدويًا شيء يستطيع الكود قوله.
2. تُنشئ اختبارات الدقة سيرفرًا وبوتات وأعضاء اختبار على سيرفر زرزور محلي، وتستدعي نقاط النهاية الموثقة برمز بوت، وتقارن الأجوبة بالمخططات، وتشغّل كل درس بوتًا حقيقيًا.
3. تُفشل فحوص آلية البناء إذا كانت نقطة نهاية بلا توثيق، أو صفحة تشير إلى لا شيء، أو مثال يستدعي مسارًا غير موجود، أو جرد قديم.

تبيّن كل نقطة نهاية كيف فُحصت:

| المستوى           | المعنى                                                   |
| ----------------- | -------------------------------------------------------- |
| فُحص حيًا         | استُدعي برمز بوت على سيرفر يعمل، وطابق الجواب المخطط      |
| تكامل محلي        | اختُبر على خدمات بدأت للاختبار                           |
| فحص الأنواع       | يُترجم مقابل أنواع المكتبة ولم يُشغَّل                   |
| سيرفر وهمي         | شُغّل على سيرفر مزيف                                      |
| غير مختبر         | معروف من الشيفرة المصدرية فقط                            |
