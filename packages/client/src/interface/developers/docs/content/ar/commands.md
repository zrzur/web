# أوامر الشرطة المائلة

سجّل أوامر يكتبها الناس بصيغة `/name`، مع خيارات وأوامر فرعية وأسماء بلغتهم.

## ما تحتاج إليه {#you-will-need}

رمز بوتك (`YOUR_BOT_TOKEN`) ومعرّفه (`YOUR_BOT_ID`). يظهر معرّف البوت في بوابة المطورين، وفي `GET /users/@me` باسم `_id`.

## عام أو لكل سيرفر {#scope}

| النطاق  | المسار                                                             | يصل إلى             |
| ------- | ------------------------------------------------------------------ | ------------------- |
| عام     | `PUT /applications/{application_id}/commands`                      | كل سيرفر فيه البوت  |
| سيرفر   | `PUT /applications/{application_id}/servers/{server_id}/commands`  | سيرفر واحد          |

يصل التغيير إلى الناس فورًا في النطاقين. استخدم سيرفر اختبار في أثناء البناء، كي لا يرى الآخرون أوامر غير مكتملة. يجب أن يكون البوت مثبتًا في ذلك السيرفر.

إذا وُجد الاسم نفسه في النطاقين، يرى الناس الأمرين.

## التسجيل {#register}

يستبدل `PUT` القائمة كاملة. وهي أسهل طريقة لإبقاء الأوامر متوافقة مع كودك: أرسل قائمتك كلما بدأ البوت. تحتفظ الأوامر غير المتغيرة بمعرّفاتها، وتُحذف الأوامر التي تركتها.

@@0

يضيف `POST /applications/{application_id}/commands` أمرًا واحدًا، ويغيّر `PATCH /applications/{application_id}/commands/{command_id}` أمرًا، ويزيل `DELETE` أمرًا. ودون كود، افتح تطبيقك في بوابة المطورين، تبويب **الأوامر**، والصق قائمة JSON.

## حقول الأمر {#fields}

| الحقل                       | المعنى                                                                                  |
| --------------------------- | --------------------------------------------------------------------------------------- |
| `name`                      | من 1 إلى 32 حرفًا صغيرًا بأي كتابة، أو أرقامًا، أو `-` أو `_`                          |
| `description`               | من 1 إلى 100 حرف. مطلوب لأوامر الشرطة المائلة، وفارغ لنوعي القوائم                     |
| `type`                      | `ChatInput` (الافتراضي، أمر `/`)، أو `User` أو `Message` (انظر أدناه)                  |
| `options`                   | حتى 25 خيارًا                                                                           |
| `name_localizations`        | الأسماء بحسب اللغة                                                                      |
| `description_localizations` | الأوصاف بحسب اللغة                                                                      |
| `default_member_permissions` | بتات الصلاحيات التي يحتاج إليها العضو ليرى الأمر ويستخدمه                              |
| `nsfw`                      | يُستخدم في القنوات الموسومة للبالغين فقط                                               |

يملأ السيرفر `_id` و`application_id` و`version`. تتغير `version` مع كل تحديث، ويُطلب ممن لديه نسخة أقدم مفتوحة إعادة التحميل.

## الحدود {#limits}

| ما يُحدّ                                                  | الحد |
| --------------------------------------------------------- | ---- |
| أوامر الشرطة المائلة لكل تطبيق ونطاق                     | 100  |
| أوامر `User` وأوامر `Message`                             | 5 لكل منهما |
| الخيارات في كل مستوى                                     | 25   |
| اختيارات الخيار الواحد                                   | 25   |
| الاسم بالأحرف                                             | 32   |
| الوصف واسم الاختيار وقيمته                               | 100  |
| النصوص المترجمة لكل حقل                                  | 30   |
| كل الأسماء والأوصاف والاختيارات معًا، مع الترجمات        | 8000 |

## الخيارات {#options}

@@1

| `type` للخيار | ما يصل إلى البوت     | حقول إضافية                                        |
| ------------- | -------------------- | -------------------------------------------------- |
| `String`      | نص                   | `min_length` و`max_length` (حتى 6000) و`choices` و`autocomplete` |
| `Integer`     | عدد صحيح             | `min_value` و`max_value` و`choices` و`autocomplete` |
| `Number`      | عدد                  | `min_value` و`max_value` و`choices` و`autocomplete` |
| `Boolean`     | `true` أو `false`    |                                                    |
| `User`        | معرّف مستخدم         |                                                    |
| `Role`        | معرّف دور            |                                                    |
| `Channel`     | معرّف قناة           | `channel_types`: `Text` أو `Voice`                 |
| `Mentionable` | معرّف مستخدم أو دور  |                                                    |
| `Attachment`  | معرّف ملف            |                                                    |

القواعد التي يفحصها السيرفر عند التسجيل:

- تأتي الخيارات `required` قبل الاختيارية.
- لا يجتمع `choices` و`autocomplete`.
- تبقى الأعداد ضمن 9007199254740991 كي تتسع لها JavaScript.

يفحص السيرفر الخيارات المطلوبة والحدود والاختيارات قبل أن يرى بوتك التفاعل. وتصل الكائنات الكاملة لـ`User` و`Role` و`Channel` و`Attachment` في `command.resolved`.

## الأوامر الفرعية {#sub-commands}

اجمع الأفعال تحت اسم واحد: `/note add` و`/note list`.

@@2

القواعد:

- يحمل `SubCommand` خيارات عادية، ولا يحمل `SubCommandGroup` إلا أوامر فرعية.
- توضع المجموعة في المستوى الأعلى، ولا يتعمق شيء أكثر من مجموعة واحدة.
- لا تختلط الأوامر الفرعية بالخيارات العادية في مستوى واحد.
- يأخذ الأمر الفرعي `name` و`description` و`options`، ولا شيء آخر.

## الأسماء بلغات أخرى {#localisation}

أعطِ كل نص بحسب اللغة. المفاتيح وسوم لغات: `ar` و`de` و`pt-BR`.

@@4

تأخذ الخيارات والاختيارات الحقول نفسها. تتبع الأسماء المترجمة قواعد `name` نفسها، فالحروف العربية مسموحة. يحمل التفاعل دائمًا `name` الأساسي، فتكفي حالة واحدة في كودك لكل أمر. ويحمل أيضًا لغة الشخص في `locale`، فتستطيع الرد بها.

## من يستطيع استخدام الأمر {#who}

`default_member_permissions` رقم مكوّن من [بتات الصلاحيات](/developers/docs/roles#permission-bits). لا يرى الأمر عضو لا يملك هذه الصلاحيات، ويحصل طلبه على `MissingPermission`. القيمة `256` هي إيقاف الأعضاء مؤقتًا. يبقى على بوتك فحص `user_permissions`: فقد يغيّر المسؤول الأدوار، والأمر ليس جدار أمان لما يفعله بوتك نفسه.

## أوامر القوائم {#menu-commands}

يُظهر `"type": "User"` و`"type": "Message"` أمرًا في قائمة مستخدم أو رسالة. لا وصف لها ولا خيارات، ويجوز في اسمها أحرف كبيرة ومسافات. يصل الهدف في `command.target_id`.

## الأخطاء الشائعة {#errors}

| الخطأ                  | السبب                                         | الحل                                     |
| ---------------------- | --------------------------------------------- | ---------------------------------------- |
| `FailedValidation`     | خُرقت قاعدة مما سبق، ويبيّن `error` أيها      | صحّح القائمة. لم يُحفظ شيء               |
| `CommandAlreadyExists` | `POST` باسم مستخدم                            | استخدم `PUT` أو `PATCH`                  |
| `TooManyCommands`      | بلغت الحد                                     | احذف أوامر                               |
| `UnknownCommand`       | المعرّف لم يعد موجودًا                        | اجلب القائمة بـ`GET`                     |
