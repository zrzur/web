# الصوت

يعمل صوت زرزور على LiveKit. تصدر الواجهة التذاكر، ويمر الصوت نفسه عبر عميل LiveKit.

## ما يعمل {#what-works}

| القدرة                                                                       | الحالة                                                                                |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| الحصول على تذكرة لقناة صوتية (`POST /channels/{target}/join_call`)           | مدعوم، وفُحص حيًا برمز بوت                                                            |
| الاتصال بـLiveKit بالتذكرة و**نشر الصوت**                                    | مدعوم. فُحص من طرف إلى طرف بـ`@livekit/rtc-node`: استقبل مشارك ثانٍ صوت البوت وقاسه   |
| استقبال صوت المشاركين الآخرين                                                | ممكن بعميل LiveKit، ويتطلب Listen. لا تغطيه اختباراتنا                                |
| نقل الأعضاء وكتمهم ومنعهم من السماع (`PATCH /servers/{server_id}/members/{member_id}`) | مدعوم مع Move Members وMute Members وDeafen Members                           |
| الفيديو ومشاركة الشاشة من بوت                                               | لم يُختبر، وتتبع التذاكر صلاحية Video                                                 |
| `force_disconnect` عند الانضمام                                             | ليس للبوتات (`IsBot`)                                                                 |
