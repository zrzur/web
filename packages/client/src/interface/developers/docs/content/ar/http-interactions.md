# التفاعلات عبر HTTP

استقبل الأوامر والأزرار والنماذج على عنوان HTTPS الخاص بك، دون اتصال بالبوابة.

> **هذه الميزة معطلة حيث يكون إعداد السيرفر `signing_key` فارغًا أو أقل من 32 بايتًا.** عندها يجيب إنشاء السر أو حفظ العنوان بالخطأ `FeatureDisabled`، وتستخدم البوتات البوابة. في السيرفر المستضاف ذاتيًا يضبط المسؤول `api.interactions.signing_key`.

## ما تحتاج إليه {#you-will-need}

- Node 22 أو أحدث، وعنوان HTTPS عام.
- رمز بوتك (`YOUR_BOT_TOKEN`) وسر التوقيع (`YOUR_SIGNING_SECRET`).
- لا نيّات اتصال: تصل التفاعلات أيًا كانت نيّات البوابة.

## الخطوات {#steps}

1. افتح بوتك في بوابة المطورين واختر **تفاعلات HTTP**. أنشئ سر توقيع وانسخه. يظهر مرة واحدة.
2. شغّل المثال أدناه على سيرفرك، والسر في `ZRZUR_SIGNING_SECRET`.
3. أدخل عنوانك في النافذة نفسها، واحفظ وأكّد كلمة مرورك. يرسل زرزور أولًا طلبي اختبار بأي ترتيب: طلبًا بتوقيع خاطئ يجب رفضه، و`Ping` موقعًا يجب أن يجاب بـ`{"type":"Pong"}`. تفعل المكتبة الأمرين عنك.

من الآن لا تستقبل البوابة تفاعلات هذا البوت. أزل العنوان للعودة.

## كيف يبدو الطلب {#what-a-request-looks-like}

كل طلب هو `POST` يحمل JSON نفسه الموجود في `interaction` داخل `InteractionCreate`، مع ثلاث ترويسات:

| الترويسة            | المعنى                                                    |
| ------------------- | --------------------------------------------------------- |
| `X-Zrzur-Timestamp` | الثواني منذ بداية التقويم عند التوقيع                     |
| `X-Zrzur-Signature` | `v1=` ثم HMAC-SHA256 بصيغة ست عشرية للنص الموقّع          |
| `X-Zrzur-Delivery`  | معرّف هذا التسليم لسجلاتك. **غير موقّع**                  |

النص الموقّع هو `v1:<timestamp>:<raw body>`. دون المكتبة:

1. ارفض الطلب بـ`401` إذا ابتعد الوقت عن ساعتك أكثر من 300 ثانية.
2. احسب HMAC-SHA256 للنص الموقّع بسرك وقارنه في زمن ثابت (`crypto.timingSafeEqual` في Node و`hmac.compare_digest` في Python). لا تقارن أبدًا بـ`==`.
3. ارفض `_id` من الجسم الموقّع إذا عالجته في الدقائق العشر الأخيرة: فهذا طلب مسروق أُعيد إرساله. لا تستخدم `X-Zrzur-Delivery` لذلك: فهو غير موقّع ويستطيع أي أحد تغييره.
4. أجب `{"type":"Ping"}` بـ`{"type":"Pong"}`.

لا يصل شيء إلى بوت معطل أو مالكه معلّق، ولا يمكن تغيير عنوانه.

تحقق بهذا المثال. مع السر `zrzur_sign_f27c5773e21ddeceaeb5e956dc45c16451f737addd5c0e4472f61060bca9b030` والوقت `1700000000` والجسم `{"type":"Ping"}` يكون التوقيع `v1=928e5ffdc88564103b59f5485a6bfa7e1a633dca64f397396606a314f572c4d3`.

## كيف ترد {#how-to-answer}

رد خلال 3 ثوانٍ بإحدى طريقتين:

- `202` أو `204` بلا جسم، ثم استدع `POST /interactions/{id}/{token}/callback` كما مع البوابة. هذا ما تفعله المكتبة.
- `200` بالجسم الذي كنت سترسله إلى ذلك المسار، مثل `{"type":"Message","data":{"content":"Hello"}}`.

أي حالة أخرى أو انتهاء المهلة أو إعادة توجيه أو جواب يتجاوز 1 ميبيبايت يُفشل التفاعل، ويرى الشخص الفشل. لا تُتبع إعادات التوجيه.

## الأخطاء الشائعة {#common-errors}

يفشل حفظ العنوان بالخطأ `SignedDeliveryRejected`، ويبيّن `reason` السبب:

| `reason`                 | السبب                                     | الحل                                  |
| ------------------------ | ----------------------------------------- | ------------------------------------- |
| `invalid_url`            | ليس `https`، أو يحمل كلمة مرور            | استخدم عنوان `https://` عاديًا        |
| `blocked_address`        | العنوان خاص أو محظور                      | استخدم عنوانًا عامًا                  |
| `not_reachable`          | لم يجب شيء                                | تحقق من أن السيرفر يعمل وأنه عام       |
| `timed_out`              | لا جواب خلال 3 ثوانٍ                      | رد أسرع                               |
| `accepts_bad_signatures` | مر الطلب ذو التوقيع الخاطئ                | افحص التواقيع وأجب `401`              |
| `bad_status`             | لم يحصل `Ping` على `200`                  | أجب `Ping` بـ`200`                    |
| `bad_answer`             | لم يحصل `Ping` على `{"type":"Pong"}`      | أرسل هذا JSON تمامًا                  |
| `answer_too_large`       | الجواب يتجاوز 1 ميبيبايت                  | أرسل جوابًا أصغر                      |

`FeatureDisabled` يعني أن هذا السيرفر بلا مفتاح توقيع مضبوط، أو مفتاحه أقل من 32 بايتًا. و`InvalidOperation` يعني أن البوت لا يملك سر توقيع بعد.
