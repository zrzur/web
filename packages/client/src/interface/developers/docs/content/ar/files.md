# الملفات

تذهب الملفات إلى سيرفر الملفات أولًا، ثم تشير إليها الرسائل والصور والرموز التعبيرية بالمعرّف.

## الرفع {#upload}

@@0

الجواب هو `{ "id": "<file id>" }`. أرسله في `attachments` داخل الرسالة، أو في `avatar` أو `icon` أو `banner` أو معرّف الرمز التعبيري.

| الوسم         | يُستخدم لـ                   | الحد الافتراضي |
| ------------- | ---------------------------- | -------------- |
| `attachments` | ملفات الرسائل                | 20 ميغابايت    |
| `avatars`     | صور المستخدمين والبوتات      | 4 ميغابايت     |
| `icons`       | أيقونات السيرفرات والقنوات   | 2.5 ميغابايت   |
| `banners`     | بانرات السيرفرات والملفات    | 6 ميغابايت     |
| `backgrounds` | خلفيات الملفات الشخصية       | 6 ميغابايت     |
| `emojis`      | الرموز التعبيرية المخصصة     | 500 كيلوبايت   |
| `sounds`      | أصوات لوحة الأصوات           | 512 كيلوبايت   |

لكل سيرفر حدوده، ويسردها `GET /` من الواجهة في `features.limits`. يقبل `attachments` أي ملف، ويقبل `sounds` صوتًا بصيغة MP3 أو OGG أو WAV لا يتجاوز 5.2 ثانية، ولا يقبل أي وسم آخر إلا الصور. وتُرفض الملفات الفارغة (`FileTooSmall`)، وتحصل الملفات الكبيرة على `FileTooLarge` مع الحد. يتطلب الرفع رمز البوت، والوسم `decorations` لفريق زرزور فقط.

## التنزيل {#download}

تُقدَّم الملفات من `https://cdn.zrzur.com/{tag}/{file id}/{file name}`. وللصور معاينات في `/{tag}/{file id}`.

## الملفات التي يعطيها الناس لبوتك {#from-people}

يسلّم خيار أمر من النوع `Attachment` وحقل نموذج من النوع `FileUpload` بوتك ملفات رفعها الناس. ويحملها التفاعل في `resolved.attachments` بمعرّفاتها، مع `tag` و`filename` و`content_type` و`size`. نزّلها كأي ملف؛ وفي المكتبة `interaction.attachmentUrl(name)` و`interaction.downloadAttachment(name)` و`interaction.fieldFiles(id)`. وعامل ما تنزّله على أنه غير موثوق: افحص نوعه وحجمه قبل فتحه.

## الأخطاء الشائعة {#errors}

| الخطأ | السبب | الحل |
| --- | --- | --- |
| `401 InvalidSession` | رمز البوت خاطئ أو أُعيد تعيينه | استخدم الرمز الحالي |
| `400 FileTooLarge` | فوق حد الوسم، ويذكر الجواب الحد الأقصى | صغّر الملف، أو افحص `features.limits` أولًا |
| `400 FileTooSmall` | ملف فارغ | أرسل محتواه |
| `400 FileTypeNotAllowed` | ليس صورة لوسم صور، أو ليس MP3 أو OGG أو WAV للوسم `sounds` | استخدم الوسم المناسب للملف |
| `403 MissingPermission` (عند الإرسال) | لا يملك البوت صلاحية رفع الملفات في القناة | امنحه الصلاحية |
| `429` | تتقاسم عمليات الرفع حدود البوت | انتظر `retry_after` ملّي ثانية |
