# الملفات

تذهب الملفات إلى سيرفر الملفات أولًا، ثم تشير إليها الرسائل والصور والرموز التعبيرية بالمعرّف.

## الرفع {#upload}

@@0

الجواب هو `{ "id": "<file id>" }`. أرسله في `attachments` داخل الرسالة، أو في `avatar` أو `icon` أو `banner` أو معرّف الرمز التعبيري.

| الوسم         | يُستخدم لـ                   | الحد الافتراضي |
| ------------- | ---------------------------- | -------------- |
| `attachments` | ملفات الرسائل                | 20 ميغابايت    |
| `avatars`     | صور المستخدمين والبوتات      | 4 ميغابايت     |
| `icons`       | أيقونات السيرفرات والقنوات   | 2.5 ميغابايت   |
| `banners`     | بانرات السيرفرات والملفات    | 6 ميغابايت     |
| `backgrounds` | خلفيات الملفات الشخصية       | 6 ميغابايت     |
| `emojis`      | الرموز التعبيرية المخصصة     | 500 كيلوبايت   |

لكل سيرفر حدوده، ويسردها `GET /` من الواجهة في `features.limits`. لا تُقبل إلا الصور ما عدا `attachments`. وتُرفض الملفات الفارغة (`FileTooSmall`)، وتحصل الملفات الكبيرة على `FileTooLarge` مع الحد. يتطلب الرفع رمز البوت، والوسم `decorations` لفريق زرزور فقط.

## التنزيل {#download}

تُقدَّم الملفات من `https://cdn.zrzur.com/{tag}/{file id}/{file name}`. وللصور معاينات في `/{tag}/{file id}`.
