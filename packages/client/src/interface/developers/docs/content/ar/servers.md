# السيرفرات

ينضم البوت إلى سيرفر حين يثبّته شخص لديه إدارة السيرفر. يستطيع قراءة السيرفر، وتغيير إعداداته بالصلاحيات المناسبة، وإدارة الرموز التعبيرية، والمغادرة.

## ما لا يستطيعه البوت {#what-a-bot-cannot-do}

- إنشاء السيرفرات أو الانضمام إليها بدعوة (`IsBot`). يثبّت المسؤولون البوتات.
- تعليم السيرفرات أو القنوات كمقروءة.
- استخدام «اكتشف» أو الفوترة أو ريشة أو الأجنحة.

## إعدادات السيرفر {#server-settings}

يغيّر `PATCH /servers/{target}` الاسم والوصف والأيقونة والبانر والفئات وقنوات رسائل النظام (يتطلب إدارة السيرفر). لا يغيّر بعض الحقول (مثل علامات التوثيق) إلا فريق زرزور.

## التطبيقات المثبتة {#installed-applications}

يسرد `GET /servers/{server_id}/applications` البوتات المثبتة في سيرفر، و`GET /servers/{server_id}/commands` الأوامر التي يستطيع الأعضاء استخدامها هناك.

## المغادرة {#leaving}

يجعل `DELETE /servers/{target}` البوت يغادر. يرى الأعضاء `ServerMemberLeave`، ويحصل البوت على `ServerDelete` لذلك السيرفر.
