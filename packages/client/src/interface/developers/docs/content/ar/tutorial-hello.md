# Hello World

بوت يجيب عن `/hello`. نسختان: واحدة بالمكتبة، وأخرى دون مكتبة لتوضيح البروتوكول.

## قبل أن تبدأ {#before-you-start}

أنشئ تطبيقًا وثبّته في سيرفر اختبار واضبط ثلاثة متغيرات بيئة (انظر [شغّل بوتك](/developers/docs/getting-started)):

@@0

## بالمكتبة {#with-the-sdk}

نفّذ `npm install @zrzur/sdk` في مجلد بوتك (Node 22.3 أو أحدث)، ثم احفظ هذا الملف فيه:

@@1

شغّله بالأمر `node hello.mjs`.

## دون مكتبة {#without-a-library}

Node 22 أو أحدث، ولا شيء لتثبيته. هذا البوت نفسه:

@@2

شغّله بالأمر `node hello-raw.mjs`.

## جرّبه {#try-it}

اكتب `/hello` في قناة من سيرفر الاختبار.

## ما يوضحه {#what-it-shows}

- يخبر `GET /users/@me` البوت بمعرّفه، ومعرّف التطبيق هو نفسه للبوتات.
- يسجل `PUT /applications/{application_id}/commands` قائمة الأوامر.
- توصل البوابة `InteractionCreate`، ويجيب البوت عبر رد التفاعل خلال 3 ثوانٍ.
- تُفتح حزم `Bulk`، ويبقي `Ping` الاتصال مفتوحًا.

> تشغّل اختباراتنا هذا الملف بوتًا حقيقيًا على سيرفر اختبار وتتحقق من أنه يجيب.
