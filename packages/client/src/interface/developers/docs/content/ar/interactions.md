# الرد على التفاعلات

كل استخدام لأمر بالشرطة المائلة أو أمر قائمة أو زر أو قائمة اختيار أو نموذج أو إكمال تلقائي يصل إلى بوتك في صورة **تفاعل**. تبيّن هذه الصفحة كيف ترد في الوقت المناسب.

## ما تحتاج إليه {#you-will-need}

اتصال بوابة يعمل مع نية الاتصال `INTERACTIONS`، أو [عنوان HTTP](/developers/docs/http-interactions). تعمل الأوامر في قنوات السيرفرات فقط. أما الأزرار والقوائم والنماذج فتعمل أيضًا في رسالة خاصة مع البوت، ويغيب عندها `server_id` و`member`.

## المهل الزمنية {#time-limits}

| المهلة                  | الوقت        | ماذا يحدث بعدها                                                         |
| ----------------------- | ------------ | ----------------------------------------------------------------------- |
| الرد الأول              | 3 ثوانٍ      | يرى الشخص أن البوت لم يرد. ويحصل الرد المتأخر على `InteractionExpired`  |
| التعديلات ورسائل المتابعة | 15 دقيقة   | يتوقف الرمز: `InteractionExpired` أو `UnknownInteraction`               |

يحمل الحدث الوقتين في `respond_by` و`expires_at`. اتبع أوقات الحدث لا ساعتك.

إذا كان العمل يستغرق أكثر من لحظة، فرد أولًا بـ`DeferredMessage`. يُظهر ذلك «يفكر» ويمنحك الدقائق الخمس عشرة.

إذا لم يكن بوتك متصلًا عند استخدام الأمر ضاع الحدث، ويرى الشخص الفشل بعد 3 ثوانٍ.

## الرد {#answer}

أرسل ردًا أولًا واحدًا. لا حاجة إلى ترويسة رمز، فالمسار يحمل الرمز.

@@2

| `type` للرد          | متى                                                       | الجسم                                |
| -------------------- | --------------------------------------------------------- | ------------------------------------ |
| `Message`            | رد الآن                                                   | `data`                               |
| `DeferredMessage`    | العمل يتجاوز 3 ثوانٍ. يُظهر «يفكر»                        | `data.ephemeral` إن كان سيبقى خاصًا  |
| `UpdateMessage`      | الأزرار والقوائم: غيّر الرسالة التي عليها المكوّن          | `data`                               |
| `DeferredUpdate`     | الأزرار والقوائم: أكّد الآن وغيّر الرسالة لاحقًا           | لا شيء                               |
| `Modal`              | افتح نموذجًا. ليس ردًا على نموذج أو إكمال تلقائي           | `modal`                              |
| `AutocompleteResult` | اقتراحات. الرد الوحيد على `Autocomplete`                  | `choices`، حتى 25                    |

يأخذ `data` الحقول `content` و`embeds` و`components` و`ephemeral`. الرد مرتين يحصل على `InteractionAlreadyAcknowledged`.

## الردود الخاصة {#ephemeral}

يُظهر `"ephemeral": true` الرد لذلك الشخص فقط. لا يُخزن أبدًا في القناة، فيختفي عند إعادة التحميل. يُتخذ القرار مرة واحدة: يبقى الرد المؤجل خاصًا بالقدر الذي حددته عند التأجيل.

## رسائل المتابعة {#follow-ups}

بعد الرد الأول تستطيع إرسال 5 رسائل أخرى للتفاعل نفسه حتى ينتهي الرمز:

@@4

يحمل الجواب `_id` الرسالة الجديدة. لرسالة المتابعة خيار `ephemeral` الخاص بها، ولا تأتي بعد رد `Modal`.

| لكي                  | المسار                                                                |
| -------------------- | --------------------------------------------------------------------- |
| تعدّل الرد الأول      | `PATCH /interactions/{interaction_id}/{token}/original`               |
| تحذف الرد الأول      | `DELETE /interactions/{interaction_id}/{token}/original`              |
| تعدّل رسالة متابعة    | `PATCH /interactions/{interaction_id}/{token}/messages/{message_id}`  |
| تحذف رسالة متابعة    | `DELETE /interactions/{interaction_id}/{token}/messages/{message_id}` |

## الإكمال التلقائي {#autocomplete}

الخيار ذو `"autocomplete": true` يطلب من بوتك اقتراحات في أثناء كتابة الشخص. يسمّي `command.focused` الخيار، وتحمل `value` النص حتى الآن، بحد 100 حرف.

@@5

رد بسرعة، فقد ترسل كل ضغطة مفتاح طلبًا. لا يقبل تفاعل `Autocomplete` إلا هذا الرد، ولا يقبله غيره.

## الأخطاء الشائعة {#errors}

| الخطأ                            | السبب                                          | الحل                         |
| -------------------------------- | ---------------------------------------------- | ---------------------------- |
| `InteractionExpired`             | تجاوزت 3 ثوانٍ أو 15 دقيقة                     | أجّل أولًا                   |
| `InteractionAlreadyAcknowledged` | رد أول ثانٍ                                    | أرسل متابعة، أو عدّل         |
| `InvalidOperation`               | الرد لا يناسب، مثل `UpdateMessage` على أمر     | راجع الجدول أعلاه            |
| `TooManyFollowups`               | أكثر من 5                                      | عدّل رسالة بدلًا من ذلك      |
| `UnknownInteraction`             | معرّف أو رمز خاطئ                              | استخدم قيم الحدث             |
