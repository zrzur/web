# OAuth2

دع الناس يسجلون الدخول إلى موقعك بحساب زرزور. يستخدم تثبيت البوت الشاشة نفسها.

## ما تحتاج إليه {#you-will-need}

تطبيق، وموقع أو برنامج يستطيع استقبال إعادة توجيه.

## ما يستطيعه وما لا يستطيعه {#scope}

يقرأ رمز الوصول هوية الشخص وسيرفراته. يعمل على `/oauth2/@me...` فقط، ولا يتصرف أبدًا باسم الشخص في بقية الواجهة.

| النطاق                  | يمنح                                      |
| ----------------------- | ----------------------------------------- |
| `identify`              | `GET /oauth2/@me`                         |
| `servers.read`          | `GET /oauth2/@me/servers`                 |
| `applications.commands` | يبيّن أن أوامرك قد تُضاف                  |
| `bot.install`           | يثبّت البوت في سيرفر يختاره الشخص         |

## أنشئ قيم PKCE {#pkce}

`code_verifier` نص عشوائي من 43 إلى 128 حرفًا. و`code_challenge` هو SHA-256 لذلك النص بترميز base64url دون حشو. احتفظ بالقيمة الأولى حتى الخطوة 5، ولا ترسل في العنوان إلا `code_challenge`.

@@4

## التحديث والإلغاء {#refresh}

تدوم رموز الوصول ساعة، ورموز التحديث 30 يومًا. يصلح كل رمز تحديث مرة واحدة ويعود جديدًا. واستخدام رمز قديم ينهي السلسلة كلها، لأن ذلك يشبه السرقة.

يأخذ المساران نموذجًا لا JSON، وهما ليسا في مستند OpenAPI. يستطيع الشخص أيضًا سحب تطبيقك من إعداداته.

## الأخطاء الشائعة {#errors}

تجيب هذه المسارات بصيغة `{ "error": "...", "error_description": "..." }`.

| `error`                  | السبب                                                | الحل                     |
| ------------------------ | ---------------------------------------------------- | ------------------------ |
| `invalid_request`        | حقل مفقود، مثل `code_verifier`                       | أرسل كل الحقول           |
| `invalid_grant`          | الرمز مجهول أو مستخدم أو منتهٍ، أو PKCE خاطئ         | ابدأ تسجيل الدخول مجددًا |
| `invalid_client`         | معرّف العميل أو سره خاطئ (الحالة `401`)              | تحقق منهما               |
| `invalid_scope`          | نطاق أوسع من الموافقة الأولى                         | اطلب أقل                 |
| `unsupported_grant_type` | نوع منح آخر                                          | استخدم النوعين أعلاه     |
