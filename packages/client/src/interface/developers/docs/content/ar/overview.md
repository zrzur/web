# واجهة برمجة بوتات زرزور

البوت حساب في زرزور يتحكم فيه برنامج. يوجد في السيرفرات كأي عضو، فيقرأ الرسائل ويرسلها، ويجيب عن أوامر الشرطة المائلة، ويعرض الأزرار والنماذج، ويشرف على السيرفر، وينشر الملفات، ويستطيع الانضمام إلى القنوات الصوتية. يثبّته الناس في سيرفراتهم، أما برنامجك فيعمل على حاسوبك أو سيرفرك.

هذه الصفحات هي كل ما تحتاج إليه. ابدأ بصفحة [شغّل بوتك](/developers/docs/getting-started)، ثم ابنِ [البوت الكامل](/developers/docs/tutorial-full-bot).

## كيف يعمل البوت {#how-a-bot-works}

1. تنشئ **تطبيقًا** في بوابة المطورين. يأتي معه مستخدم بوت و**رمز**، وهو كلمة مرور البوت.
2. يثبّت شخص لديه صلاحية إدارة السيرفر البوت **في سيرفر** ويمنحه صلاحيات.
3. يستدعي برنامجك **واجهة REST** عبر HTTPS واضعًا الرمز في الترويسة `x-bot-token`. هكذا يتصرف البوت.
4. يبقي برنامجك اتصالًا واحدًا مفتوحًا مع **البوابة**، وهو WebSocket. هكذا يسمع البوت: تصله الأوامر ونقرات الأزرار والرسائل وتغييرات الأعضاء في صورة أحداث.

## الطريق من الصفر إلى بوت جاهز {#the-path}

1. [شغّل بوتك](/developers/docs/getting-started): تطبيق ورمز وأول أمر.
2. [التطبيقات والرموز](/developers/docs/applications): كل إعدادات بوابة المطورين، وكيف تثبّت البوت.
3. [البوابة](/developers/docs/gateway): اتصل، وابقَ متصلًا، وعد بعد أي انقطاع.
4. [أوامر الشرطة المائلة](/developers/docs/commands) و[الرد على التفاعلات](/developers/docs/interactions) و[الأزرار والقوائم والنماذج](/developers/docs/components).
5. [الرسائل](/developers/docs/messages) و[الأدوار والصلاحيات](/developers/docs/roles) و[الإشراف](/developers/docs/moderation).
6. [الأخطاء](/developers/docs/errors) و[حدود المعدل](/developers/docs/rate-limits) و[حماية الرموز](/developers/docs/security) و[التشغيل الفعلي](/developers/docs/production).

## العناوين الأساسية {#base-urls}

| الخدمة             | العنوان                 |
| ------------------- | ----------------------- |
| واجهة REST          | `https://api.zrzur.com` |
| البوابة (WebSocket) | `wss://ws.zrzur.com`    |
| الملفات             | `https://cdn.zrzur.com` |
| الصوت (LiveKit)     | `wss://voice.zrzur.com` |

للسيرفرات المستضافة ذاتيًا عناوينها الخاصة. يعيدها `GET /` من الواجهة مع حدود ذلك السيرفر.

## ما لا يدعمه النظام {#not-supported}

- **التجزئة (Sharding).** للبوت اتصال واحد، أو عدة اتصالات يستقبل كل منها كل شيء. لا يمكن توزيع الأحداث بين العمليات.
- **استئناف الاتصال.** لا توجد جلسة تُستأنف. بعد الانقطاع يصلك `Ready` جديد، ولا يُعاد إرسال ما حدث في أثناء الانقطاع.
- **الأوامر في الرسائل الخاصة.** تعمل الأوامر في قنوات السيرفرات فقط. أما الأزرار والقوائم والنماذج فتعمل أيضًا في رسالة خاصة مع البوت.
- **التفاعلات عبر HTTP** على سيرفر إعداده `signing_key` فارغ. تجيب المسارات هناك بالخطأ `FeatureDisabled`، وتستخدم البوتات البوابة.
- **إنشاء البوتات أو السيرفرات عبر بوت، أو الانضمام بدعوة، أو الصداقات.** هذه للأشخاص. تسرد [صفحة التغطية](/developers/docs/coverage) كل نقطة نهاية تُرفض فيها البوتات.
- **المكتبة في صورة حزمة.** ليست على npm بعد، ومستودعها ليس عامًا بعد. كل صفحة هنا تعمل بـNode وحده، وانظر [المكتبات](/developers/docs/sdk).
